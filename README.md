# STICK//BREAK

네온 옥상을 배경으로 한 데스크톱용 졸라맨 액션 게임입니다. 설치나 빌드 없이 실행할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나, 로컬 서버를 실행하세요.

```bash
python3 -m http.server 8080
```

그 후 `http://localhost:8080`으로 접속합니다.

## 조작

- `A` / `D` 또는 방향키: 이동
- `Space`, `W`, `↑`: 점프 및 2단 점프
- `J`: 3단 근접 콤보
- `K`: 에너지 샷
- `Q`: 충격파 (에너지 35)
- `E`: 집중 모드 (4초간 적 감속, 에너지 30)
- `X`: 필살기 (에너지 100 필요)
- 보스 처치 후 `VOID NOVA`, `CHAIN ARC`, `TIME REAVER` 중 하나를 선택할 수 있습니다. 마우스 클릭 또는 숫자 `1`·`2`·`3`으로 선택합니다.
- `Shift`: 무적 대시
- `P`: 일시정지
- `R`: 재시작
- `F`: 전체화면
- `M`: 사운드 켜기/끄기

총 6개의 웨이브에 3명의 보스가 등장합니다. 각 보스를 처치할 때마다 전장이 3종의 네온 배경 중 하나로 랜덤 변경됩니다.
